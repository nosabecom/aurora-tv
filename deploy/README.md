# Original interface profile

Use config.json with the unchanged upstream UI. Copy the regular wallpaper from
[the upstream Aurora theme](../themes/aurora/wallpaper.jpg), or a locally chosen image, to the app's
theme wallpaper.jpg through its permission-protected provider. The original renderer fills/crops it.
Never add personal wallpaper images or album links to this directory.

Settings opens Android TV settings directly; Wi-Fi and Inputs remain visible. The dock stays Netflix,
Prime Video, Disney+, YouTube. All original library, reorder, tile-menu and module-card behavior remains.
No custom app-layout choices or network photo integration are added.
